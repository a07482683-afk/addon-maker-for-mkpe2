# Addon Maker for MCPE

Простая настольная программа для создания аддонов Minecraft Bedrock.

## Как пользоваться

1. Нажмите **«Создать проект»** или **«Открыть проект»**.
2. Выберите нужный редактор: предмет, блок, броня, текстура или модель.
3. Нажмите **«Сохранить в проект»** в редакторе.
4. Когда закончите, нажмите **«Экспортировать .mcaddon»**. Программа соберёт Behavior Pack и Resource Pack в один файл.

## Что уже есть

- Создание проекта с папками BP и RP и стартовыми manifest-файлами.
- Упрощённая главная страница на русском языке с последовательными шагами.
- Предметы, блоки и броня: простые формы для основных параметров и предпросмотр JSON.
- Текстурный редактор с кистью, ластиком, заливкой, слоями, отменой и экспортом PNG.
- Регистрация PNG-текстур в Resource Pack.
- Импорт OBJ и ASCII FBX, 3D-просмотр и экспорт стартовой геометрии/анимации.
- Сборка .mcaddon из двух отдельных .mcpack архивов с проверкой manifest.json.
- GitHub Actions сборка Windows x64.

## Важно

Некоторые редакторы пока создают стартовые JSON-шаблоны, а не все возможные варианты Bedrock. Импортёр поддерживает OBJ и ASCII FBX; бинарный FBX не поддерживается. Геометрия модели пока представлена кубами по габаритам частей, а не исходной сеткой. Перед публикацией проверяйте аддон в своей версии Minecraft Bedrock.

## Windows 7

Проект использует Python 3.8.10 x64, PySide2 5.15.2.1 и PyInstaller 5.13.2 как целевую старую связку. Совместимость готового EXE с чистой Windows 7 SP1 x64 всё ещё нужно проверить на реальном компьютере.
